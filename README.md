# A Spot of Bother: Mischief in Mayfair

A comic open-city game set in Mayfair in 1934. You are the Hon. Teddy Wrenfield, a young man of means and very little sense. You walk, you borrow motors, you pinch things from people who have them, and you try to keep your aunt from hearing about any of it.

Play it in the browser: https://dmdronsfield-oss.github.io/top-down/

## Controls

| Key | On foot | In a motor |
| --- | --- | --- |
| Arrows or WASD | Walk | Drive and steer |
| Shift | Run | |
| E or Enter | Talk, pinch, pick up, go in | |
| F | Get into the nearest motor | Get out |
| Space | | Handbrake |
| G | | Horn |
| Q and R | Turn the view | |
| H | Ask Mortlake for a hint | |
| M or Tab | Pocket atlas | |
| Esc or P | Pause | |
| N | Mute | |

A gamepad also works.

## Building

```
npm install
npm run dev      # play locally
npm run build    # production build into dist/
```

Every push to `main` is built and published to GitHub Pages by `.github/workflows/pages.yml`.
