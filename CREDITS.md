# Credits

## Character models

People are built from the **Ultimate Modular Men** and **Ultimate Modular Women** packs by **Quaternius** (https://quaternius.com), released under **CC0 1.0** (public domain). The models were converted to compressed glTF with `tools/prepare-models.mjs`, recoloured in the game for 1934 dress, and given hats, props and outlines made in code.

## Code

- three.js (MIT licence), https://threejs.org
- Vite (MIT licence), https://vitejs.dev
- glTF-Transform and meshoptimizer (MIT licence), used only at build time.

## Everything else

Buildings, motors, street furniture, textures, portraits, sounds and writing were made for this game in code. Street names are real Mayfair streets; every shop, club, pub and person is invented.

## Fonts

Limelight, Josefin Sans and Libre Baskerville from Google Fonts (SIL Open Font Licence).
